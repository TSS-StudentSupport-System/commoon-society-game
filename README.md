# COMMOON SOCIETY v0.4 · คำสาปแสงจันทร์ที่โรงเรียนมูนสคูล

เกมบอร์ดผู้เล่นหลายคนบนเบราว์เซอร์สำหรับห้องเรียน SEL เรื่องการกลั่นแกล้งในโรงเรียน (จอโปรเจกเตอร์ + มือถือนักเรียน)

## เริ่มใช้
```
npm install
npm start          # http://localhost:3000  (เครื่องอื่นใน Wi-Fi เดียวกันใช้ IP ที่แสดง)
npm test           # ทดสอบระบบ + บอทเล่นจนจบทั้ง 3 โหมด
npm run sim        # บอทเล่น 50 เกมต่อโหมด แล้วรายงานสมดุล (node scripts/simulate.js [จำนวนเกม] [จำนวนคน])
```

## ทดลองเล่นกับบอท
สร้างห้อง → ในล็อบบี้กด "+4 บอท" หรือ "+10 บอท" → เริ่มเกม · เปิดมือถือหรือแท็บอื่นเข้าร่วมด้วยตัวเองได้ · บอทเล่นผ่านกติกาเดียวกับคน

กติกาทั้งหมด: `docs/GAME_RULES.md` · ไพ่ 100 ใบ: `server/data/scenarios.csv` · ตัวเลขทั้งหมด: `server/content.js`
